# 写分镜（STORYBOARD.md）

分镜是整支 MV 的设计文件，也是每个章节（或章节子代理）的任务书。**画风固定、内容跟着歌词走**：水彩加墨线的绘本画风、
镜头语言和作画规则照 `ANIMATION_GUIDE.md`；构思、角色、场景、道具每首歌从歌词重新设计。

## 输入

- `src/config.js`（时长、BPM、首拍 offset）、`src/lyrics.js`（每句起止）、`assets/analysis.json`（每小节响度 `bars`、`downbeat`）。
- 歌词本身：讲了什么故事、情绪怎么走、出现了哪些人/动物/物件/地点/梗。
- 用户给的方向；没有就用默认方向：每句歌词都有有趣的画面和转场；可爱、卡通、色彩欢快但柔和、动画活泼、每个镜头都有事发生；少字。

## 步骤

1. **分段 → 章节**：前奏、主歌、副歌、桥段、间奏、尾奏，一段一章（> 约 25 s 可拆，< 约 8 s 并到相邻章）。`bars` 的响度跳变帮你找边界。
   章节首尾相接铺满 0 到结尾；记下每章第一拍 `n = ceil((start - offset) / beat)`，章节文件里写 `const B = n => OFF + n * BEAT;`。
2. **构思**：一个贯穿全片、有升级、有反转的点子，**首尾呼应**（开头和结尾是同一个画面）。写下两条规则：每个镜头都有事发生；少字。
3. **角色**（宁少勿多）：主角 1–2 个（通常是“我”和“你”）、群演（主角造型变体）、每段主歌一个客串、可选一个反复出现并逐段升级的象征。
   每个角色一份风格简报：是什么、性格、一眼认得出的剪影、主色/暗色/亮色、标志特征、脸、和别人的大小关系。Clawd 只是默认演员，歌词不指向时别用。
4. **场景与串联**：每章一个地方（来自这一章歌词的意象），相机在其中移动；副歌回到同一个“主场景”并逐次加码；
   少数章节交界用笔刷擦除（`brushWipe`），其余用动作带过切点（吞镜头、坠落、钻进眼睛、泡泡戳破、甩镜…）；情绪变形不硬切；
   每章一个调色，跟着歌的情绪走；副歌和舞蹈镜头里主角约占画面高度 40%。
5. **镜头表**：每章一节 `## N · 章节名（start–end）· 场景 · 调色`，表头 `| 时间 | 歌词 | 镜头 | 出 |`。一句歌词一个镜头（1.4–4 s，
   超过约 4 s 可拆两镜，间奏写成舞蹈/动作镜头）。“镜头”写具体发生什么（谁、做什么、哪里好笑、相机怎么动、哪个动作卡在拍上），
   “出”写怎么带进下一个镜头；章节最后一镜的“出”要和下一章第一镜对上。
6. **歌曲信息**（写在最前面）：时长、BPM、拍长、小节长、首拍、各章起止/第一拍/场景/调色、笔刷擦除时刻、“卡拉 OK 条盖住底部 y≈975–1070”。

## 模板

```markdown
# 《歌名》：分镜
## 歌曲信息
- 时长 … s · … BPM · 拍长 … s · 小节 … s · 首拍 … s，拍点 = offset + n × beat
- 卡拉 OK 条在有歌词时盖住底部 y≈975–1070；笔刷擦除：…
| 章 | 文件 | 时间 | 第一拍 | 场景 | 调色 | 入场 |
|---|---|---|---|---|---|---|
## 构思
…（点子、升级、结尾反转、首尾呼应的画面）
## 角色
| 谁 | 歌词依据 | 造型（风格简报） | 作用与弧线 | 实现 |
|---|---|---|---|---|
## 场景与串联规则
---
## 1 · 章节名（0–…）· 场景 · 调色
| 时间 | 歌词 | 镜头 | 出 |
|---|---|---|---|
```

## 交付前自查

- [ ] 章节首尾相接铺满全片；每句歌词都有镜头，每个镜头都有具体动作，没有标签/说明文字
- [ ] 构思、角色、场景都能在歌词里找到依据；主角 1–2 个、客串克制、每个角色有风格简报
- [ ] 每章一个场景；副歌有主场景并逐次加码；每个交界都写了“出”并对上
- [ ] 结尾与开场首尾呼应；分镜已给用户过目
